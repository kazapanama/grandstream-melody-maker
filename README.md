# GSRing

Рінгтони для IP-телефонів **Grandstream** з будь-якого аудіо чи відео. Відкриваєш пісню,
вирізаєш потрібний шматок, слухаєш, як він звучатиме на телефоні, і забираєш готовий `ring1.bin`.

Один exe на 45 КБ — без інсталятора, Python, FFmpeg чи прав адміністратора.

## Запуск

Завантаж [`GSRing.exe`](GSRing.exe) і запусти. Відкриється вікно застосунку.

Потрібні Windows 10/11 і Edge або Chrome. Файли обробляються локально й нікуди не надсилаються.

## Можливості

- **Будь-який вхід:** mp3, wav, m4a, aac, ogg, opus, flac, mp4, webm.
- **Обрізка по хвилі:** ручки початку й кінця, перетягування виділення, зум колесом.
- **Прослуховування з будь-якого місця:** клік по хвилі — грає звідти.
- **Межа звучить одразу:** посунув кінець — чуєш останні 3 секунди перед ним.
- **«Як на телефоні»:** прев'ю після кодування 8 кГц μ-law, тобто саме те, що заграє апарат.
- **Обробка:** нормалізація гучності, підсилення, fade in/out, телефонний фільтр 300–3400 Гц.
- **Довжина** 8, 16 або 24 секунди; вихід `ring1.bin` / `ring2.bin` / `ring3.bin` і за потреби WAV.

## Як користуватись

1. Перетягни файл у вікно.
2. Виділи фрагмент на хвилі й підлаштуй межі ручками.
3. Клікай по хвилі, щоб послухати потрібні місця, і перевір результат кнопкою «Як на телефоні».
4. Натисни «Створити та завантажити .bin».

| Дія | Як |
|-----|----|
| Слухати з місця | клік по хвилі або шкалі |
| Ще раз / стоп | Пробіл |
| Пауза / продовжити | P |
| Стоп | Esc |
| Початок / кінець там, де грає | `[` / `]` |
| Скасувати зміну меж | Ctrl+Z |
| Зум / прокрутка | колесо / Shift+колесо |

## Заливання на телефон

Веб-інтерфейс телефона → **Maintenance → Upgrade and Provisioning → Ring Tone**, або поклади
`ring1.bin` на TFTP/HTTP-сервер провізіонінгу. Потім на телефоні обери Custom Ring Tone 1/2/3.

> Режими 8 і 16 с звірені з файлами оригінальної утиліти Grandstream; 24 с варто перевірити на своєму апараті.

## Командний рядок

Для пакетної обробки й форматів, яких не читає браузер (mkv, avi, wma), є `src/gsring.py`.
Потрібні Python 3.10+ і `ffmpeg` у `PATH`.

```bash
python src/gsring.py song.mp3  -o ring1.bin -s 42 -l 16     # 16 с починаючи з 0:42
python src/gsring.py video.mp4 -o ring2.bin --phone-filter --gain 3
python src/gsring.py ring1.bin --inspect                    # показати вміст готового .bin
```

## Збірка

```bat
build.cmd
```

Збирає `GSRing.exe` компілятором C#, що входить до Windows, — нічого ставити не треба.
Сам застосунок — `src/index.html`, його можна відкрити й просто в браузері.
